從預測比分，找出真正有 Edge 的盤

本功能不是從既有報告頁抓資料，而是直接串接各大國際盤 odds API，將 NBA / MLB 預測比分轉換成 moneyline、讓分與大小分機率，再與台灣運彩拍照 OCR 的盤口互相比對。

比數轉賠率

Moneyline

model_home_prob = score_model_home_win_probability
home_fair_odds = 1 / model_home_prob
away_fair_odds = 1 / (1 - model_home_prob)

Spread / Total

spread_cover_prob = P(model_margin > sportsbook_spread)
over_prob = P(model_total > sportsbook_total)

三方比對欄位

欄位用途

International best odds各大國際盤中同市場、同盤口最佳賠率。
Sharp no-vig probability去水後市場共識機率，Pinnacle 或 sharp source 優先。

Edge / EV / Kelly判斷是否正期望值，以及建議投注比例。

台灣運彩 OCR

OCR 只做初步辨識，必須提供人工校正。尤其是隊名、讓分正負號、大小分盤口與小數賠率，任何一個錯誤都會讓 Edge 計算失真。

  • 上傳照片後建立 ocr_upload 紀錄。
  • 解析 game、market、line、odds、timestamp、confidence。
  • 顯示校正 UI，使用者確認後才進入比對。
  • 同市場同盤口才直接比；盤口不同時需重新計算 cover probability。
